# Data Dictionary

## Provenance labels
| Label | Meaning |
|---|---|
| `data_origin = 'synthetic'` | Generated by `app/ml/synthetic.py`. Never real customers. |
| `data_origin = 'real'` | Requests that went through the TokenGuard gateway. |
| `provider = 'anthropic-mock'` | Gateway request served by the offline mock (mock mode). Token counts are estimates and no provider call was made. |
| `provider = 'anthropic'` | A real Anthropic Messages API call. Tokens come from the response's `usage` metadata. |

Synthetic and real rows are never presented as equivalent evidence. Forecast runs store the mix in `data_mix_json`, and the API returns `evidence_type`.

## Generated files (`data/generated/`, git-ignored; regenerate with `scripts/generate_synthetic.py`)
| File | Grain | Key columns |
|---|---|---|
| `requests_synthetic.csv` | one row per (raw, uncleaned) request | `request_id`, `occurred_at` (UTC), `recorded_at`, `day` (Asia/Kuala_Lumpur), `app_id`, `request_category`, `model`, `input_tokens`, `output_tokens` (may be missing), `cost_myr`, `fingerprint`, `client_fingerprint`. **Ground truth, never features:** `cache_eligible`, `faq_intent`, `paraphrase_class`, `matcher_recognizes`, `is_retry`, `is_extreme_legit`, `scenario_id` |
| `daily_usage_synthetic.csv` | day × app × category × model (after cleaning) | `requests`, `input_tokens`, `output_tokens`, `cost_myr`, `cache_hits`, `retry_requests` (inferred from the log, not from labels) |
| `anomaly_truth.csv` | one row per injected event | `event_id`, `kind` (A1–A8), `app_id`, `metric`, `start_date`, `end_date`, `mechanism`, `magnitude`, `event_class` (business_spend / technical_fault / operational_outage / benign / data_quality), `alert_expected` (yes / no / drift), `split` |
| `scenario_truth.csv` | day × app | potential outcomes on the same demand stream: `baseline_cost_myr`, `avoided_cost_myr`, `overhead_myr`, `cached_cost_myr`, `true_net_savings_myr` |
| `dataset_manifest.json` | dataset | seed, period, splits, assumptions, pricing version, FX, data-quality report, SHA-256 of every file |

## Injected events
| Kind | Mechanism | Alert expected |
|---|---|---|
| A1 | 3× request traffic for 2 days (campaign / viral demand) | yes |
| A2 | 4× input tokens per request for 3 days (prompt bloat) | yes |
| A3 | 60% of traffic moved to a more expensive model for 5 days | yes |
| A4 | 35% of requests retried once, 1–30 s later, for 2 days | yes |
| A5 | traffic × 0.03 for 2 days (outage) | yes (operational) |
| A6 | +2%/day cost over 14 days; the higher level persists | drift (scored per event) |
| A7 | one-day 1.8× weekend promotion | no (hard negative) |
| A8 | missing output tokens, duplicate rows, delayed / out-of-order records, extreme legitimate requests | no (robustness) |

## Database tables (see `apps/api/app/models.py`)
- `api_requests`: request metadata only. There is no message text; `request_fingerprint` and `client_fingerprint` are keyed HMACs. `cache_status` (miss / exact_hit / semantic_hit / bypass / error) says what happened. `cache_decision` records the safety gate and match outcome for every request, prefixed `shadow_` while the policy is disabled and `holdout_` for the opt-in control group.
- `response_cache`: one row per normalized query that was served an approved FAQ answer (TTL, knowledge version, hit count). It never stores model-generated text.
- `scenario_runs` / `recommendations` / `policies` / `policy_audit`: what-if results computed from a persisted forecast, proposed decisions (with optimistic `version`), per-app cache policy, and the append-only audit trail.
- `daily_usage`: per workspace × app × day × category × model × origin. Real rows are rebuilt by `aggregate_real_usage` for complete days only.
- `forecast_runs` / `forecast_points`: each run plus per-day, per-segment predictions with bounds.
- `anomaly_events`: merged alert events with reason code, observed vs expected values, impact and explanation.
- `evaluation_runs`: offline evaluation results (`offline_synthetic_v1`) and each workspace's dataset manifest plus injected truth (`synthetic_dataset`).
